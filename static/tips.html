详细说明

签证入境 换钱支付 交通 安全电话 礼仪 天气行装 上网通信 防骗提醒

面向持中华人民共和国普通护照的短期游客。政策会调整，本页在 2026年11月15日 根据官方公开页面核对，出行前请再查原文。

签证入境
  1. 持中国普通护照前往首尔、釜山等济州以外地区，原则上需要事先取得韩国签证。济州岛对符合条件的游客可免签停留 30 天，但须从境外直达济州口岸入境，且活动范围仅限济州；经仁川、金浦、釜山等地中转，一般不能使用济州免签。符合条件的中国团队游客另有阶段性免签政策，细则以韩国驻华使领馆公告为准。
  2. K-ETA（韩国电子旅行许可）是给免签入境对象国家/地区旅客办的出发前许可，不能代替中国游客前往首尔等地所需的旅游签证。持有效签证前往韩国本土，一般不必再办 K-ETA。中国游客若乘直达航班或船舶免签进入济州，通常也不在 K-ETA 办理对象之列。是否需要办理，请以官网 k-eta.go.kr 查询为准，不要使用非官方代办网站。
  3. 免签或持签证都不等于一定能入境。建议备好返程机票、首晚住宿订单和行程说明，入境审查时可能抽查。
  4. 韩国官方并未统一要求护照剩余有效期必须超过 6 个月，但护照须在整个停留期间保持有效。航空公司和出发地边检可能另有要求，出发前建议确认，并预留空白签证页。
机票和机场
  1. 仁川机场国际航班较多，离市区较远；金浦离市区更近，去弘大、明洞通常更方便。具体以当时航班和交通时间为准。
  2. 仁川到市区可乘坐机场铁路（AREX）、机场大巴、出租车，也可预先预约包车。行李较多、需要点对点前往医院面诊时，不少游客会选择包车；费用和包含项目请事先书面确认。
  3. 若要在机场办理退税和托运，建议比航班更早到达，预留排队和海关查验时间。
  4. 机场兑换处方便，但牌价常常不如市区正规兑换所，适合只换少量应急现金。
住宿
  1. 明洞购物和交通方便；弘大较年轻热闹；江南一带皮肤科和医美机构较多；乙支路附近相对安静，有时性价比更好。住哪里取决于行程，不是绝对标准。
  2. 不少韩国酒店不提供一次性牙刷、牙膏或拖鞋，建议自带。
  3. 韩国酒店常见入住 15:00、退房 11:00，以各酒店规定为准。能否提前入住要看当天房态，有的免费、有的收费；多数酒店可免费寄存行李。
  4. 入住房间人数一般按预订和登记来，不要私自加住未登记的人。
交通
  1. T-money 等交通卡可在地铁、公交和部分便利店使用，便利店和地铁站通常可购买、充值。余额退还可在指定地点办理，一般会扣除手续费，卡本身工本费通常不退。
  2. 公交上下车都建议刷卡。不刷下车，在首尔市内线路上通常主要是无法享受换乘优惠；在实行距离计费的线路（如部分京畿道公交）上，还可能按该线路较高票价扣费。
  3. 白色或银色多为普通出租，黑色模范出租起步价和单价更高。首尔普通出租夜间加价时段目前一般为 22:00–04:00，其中 23:00–02:00 加价幅度更高；其他城市可能不同，以上车时计价器为准。
  4. 部分叫车应用提供中文界面。给司机看韩文地址，或发送 Naver 地图地点链接，通常比只说中文店名更稳妥。本站地点页也提供 Naver 地图和高德地图按钮。
  5. 深夜公共交通班次较少，虽有部分夜班公交，但多人出行或带行李时，可考虑出租车或预先预约的包车。
换钱、支付和退税
  1. 换钱请选择有公示汇率的银行或正规兑换所（明洞一带选择较多），当场点清；不要私下找人换钱。
  2. 百货、Olive Young、免税店等较大商户越来越多支持微信、支付宝，但路边小摊、传统市场和不少小店仍可能只收现金或韩国卡，建议准备少量韩元。
  3. 在贴有退税标识的商店，单笔消费达到 15,000 韩元及以上 才可能退税（不是以前常说的 3 万韩元）。结账时出示护照并主动说明要退税。即时退税和一般退税的单笔、累计上限不同，详见本站 购物与退税 页。
  4. 在市内免税店购买、约定机场提货的商品，一般须在出境时提取，在韩国境内通常不能拆开使用。事后退税的商品出境前也应保持未使用，以便海关查验。
网络和常用工具
  1. 短期旅游很多人优先办理 eSIM，不用更换实体卡，但手机需支持 eSIM 且已解锁。也可以在机场办理预付 SIM 或租用随身 Wi-Fi。
  2. 在韩国，导航优先用 Naver 地图，翻译可用 Papago；谷歌地图在部分步行和公交线路上可能不够完整。
  3. 韩国常用电压 220V、60Hz，插座为两个圆孔（对应常见的欧标或德标转换头），请携带转换插头。
游玩打卡
  1. 穿着符合规定的韩服参观景福宫等部分宫殿，可免门票；服装须符合官方指引。热门时段建议提前查看是否需要预约。
  2. 弘大街头公演多在傍晚，周末通常更多，具体时间和地点不固定。
  3. 汉江公园可以野餐、租自行车，炸鸡和杯面是常见搭配；请把垃圾带走，并遵守公园规定。
  4. 爱宝乐园更偏大型园区和户外景区，乐天世界在市区、交通更方便，选择取决于行程和天气。
  5. 韩国公休日部分小店和餐厅会休息，出行前查好日期和营业时间。
美食
  1. 不少烤肉店设有 2 人起订，单独用餐可事先问清，或寻找标明接待单人的店铺。
  2. 韩国日常餐饮一般没有付小费的习惯；若账单已写服务费，按账单支付即可。
  3. 街边小吃、广藏市场等很多摊位可能只收现金，建议随身带一些韩元。
购物
  1. Olive Young 是常见的药妆连锁，不少门店可办理退税，进店请看退税标识，结账前向店员确认。
  2. 东大门部分商圈凌晨仍营业，批发和零售楼层不同，有的档口可能不接受单件散客，先问再买。
  3. 秋冬常有大型促销，部分商家也会做年末或圣诞折扣，力度因店而异。
  4. 大量采购回国时，注意中国海关对个人自用物品的限额，超额可能需申报或征税，以海关总署最新规定为准。
医美和皮肤科
  1. 请选择有正规资质的皮肤科或整形外科等医疗机构，避开无法确认资质的小店。
  2. 面诊时可询问医生资质、是否提供中文沟通或翻译，以及书面费用明细。
  3. 价格和项目因医院而异，建议向多家机构了解，并看清是否另有检查、药品或售后费用，不要轻信「一定同价」「绝无额外消费」这类口头承诺。
  4. 不同项目恢复期不同，面诊时问清楚能否正常逛街、何时适合乘飞机返回。
  5. 术后药品建议保留原包装，按航空和海关规定随身携带。本站只提供一般出行提示，不推荐或担保任何医疗机构。
接送机和包车
  1. 可预约接送机或包车。价格是一口价还是另计，航班延误是否收取等待费，因服务商而异，请事先书面确认。
  2. 包车常见按小时或按日计价，停车费、高速费是否包含在内，下单前问清。
  3. 有的行程可一并安排接送机、住宿协助、就医陪同或购物翻译，服务范围以合同为准。
  4. 选择时确认是否有强制购物安排，并保留订单和联系方式。本站不指定或推广某一车行。
入境限制和安全
  1. 新鲜水果、蔬菜以及肉类、火腿、香肠等畜产品，旅客一般不得擅自带入韩国，须申报并接受检疫，违规可能被罚款或处罚。
  2. 常用药品尽量带原包装和说明书；数量较多或处方药，建议备好处方或医生证明，入境时按海关要求申报。
  3. 地铁、公交车内以及许多公共场所、指定禁烟区禁止吸烟，请到指定吸烟区。违者可能被罚款，金额因地方规定而异。
  4. 未经允许不要随意拍摄路人、店员，以免引发纠纷。
  5. 旅游咨询可拨打 1330，VisitKorea 写明提供中文等语言服务（在韩国拨 1330，境外可试 +82-2-1330）。报警 112，急救和火警 119。
其他
  1. 首尔整体治安相对较好，但独自出行仍建议选择人多、照明好的路段，尽量避开偏僻小巷。
  2. CU、GS25、7-Eleven 等便利店购买零食、饮料和简单餐食很方便，部分门店 24 小时营业。
  3. 春秋昼夜温差大，建议穿可叠加的衣服；冬天室内暖气通常很足，外套方便穿脱更舒服。

1. 签证与入境

去首尔、釜山等韩国本土

持普通护照的中国公民前往首尔、釜山等济州以外地区，原则上需要事先取得韩国签证。观光常用的是短期访问（C-3）类别中的一般旅游（C-3-9）等，具体发给对象、停留期和材料以韩国驻华使领馆及签证申请中心的说明为准。

韩国旅游发展局 VisitKorea 也提醒：除济州免签、符合条件的过境等情形外，中国游客访问济州以外地区需要准备签证。申请途径包括各地韩国签证申请中心或使领馆指定机构。

关于 K-ETA

韩国电子旅行许可（K-ETA）是给「免签入境对象国家/地区」旅客，在出发前于官网或官方应用申请的许可。中国不属于免签入境韩国本土的国家，因此不能用「先办 K-ETA、再免签去首尔」来替代旅游签证。

韩国法务部曾对部分免签国家/地区实施 K-ETA 阶段性免除，并延长至 2026年12月31日。官方列出的免除地区包括日本、中国香港、中国澳门、台湾、新加坡及美、加、部分欧洲国家和澳大利亚、新西兰等，名单中不包括中国大陆。请以 k-eta.go.kr 为准，不要使用非官方代办网站。

济州免签

韩国驻华使领馆说明：以旅游、过境等为目的，乘坐直达济州的飞机或船舶，经济州口岸入境的个人及团体游客（中国游客包含在内），可在仅限济州岛的范围内停留30天以内。经首尔、釜山等韩国其他地区中转再去济州，一般不能使用这一济州免签，而需要相应签证。

免签不等于一定能入境。中国驻济州总领事馆曾提醒：入境审查官员有权拒绝入境，建议备好行程单、酒店订单和往返机票等，以备查验。

中国团队游客阶段性免签

大韩民国驻上海总领事馆 2026年6月22日公告：自 2025年9月29 日起实施的中国团队游客阶段性免签政策，实施期限延长为 2026年7月1日至2026年12月31日。更新：韩国驻华大使馆 2026年11月24日发布延长通知，据韩国法务部、外交部消息，该政策再延长至 2027年12月31日，条件不变（3人以上、指定专责旅行社、最长15天）。韩国驻新加坡大使馆的说明则强调：适用对象是在中国参加特定团队旅游的中国公民，须向驻华使领馆核实细则。

团队人数、停留天数、指定旅行社名单和出发地限制，本页不臆测，请以驻华使领馆最新公告和指定旅行社名单为准。政策到期后是否再延长，也需要再查官方。

签证与入境咨询：韩国出入境咨询 1345（在韩国拨打）；详情见韩国签证门户 visa.go.kr、HiKorea hikorea.go.kr。

2. 货币与兑换

韩国使用韩元（KRW，符号 ₩）。纸币常见面额为 1,000、5,000、10,000、50,000 韩元。兑换请选择银行或公示汇率的正规兑换所，并在柜台当面点清现金。

很多旅客会比较仁川机场兑换处和明洞、南大门一带兑换所的牌价。市区兑换所的牌价常常更有利，但每家手续费、是否收取额外费用并不相同，请当场比较，不要只听拉客报价。机场兑换方便但未必划算，适合只换少量应急现金。

餐饮、便利店、商场普遍可刷卡。VisitKorea 介绍的退税柜台也支持部分情形下的人民币现金、支付宝或微信支付（以各机场柜台当日说明为准）。支付宝、微信支付在旅游区和部分商店越来越常见，但传统市场摊位仍可能只收现金或韩国卡，建议准备少量韩元现金。

银联卡在部分商户和ATM可用，能否取现、是否收费取决于发卡行和ATM，请向自己的银行确认。

3. 交通

交通卡

T-money 等交通卡可在地铁、公交和部分便利店使用，可在便利店、地铁站和机场购买、充值。是最常规的游客选择。

WOWPASS 是面向游客的多功能预付卡，VisitKorea 有专门介绍，可用于交通和部分消费，并支持用外币充值等功能，具体以官方说明和办理点为准。

气候同行卡（Climate Card）短期券：据首尔市官方介绍（页面修订日 2026-10-12），一次充值后可在所选天数内无限乘坐指定公共交通。覆盖范围为首尔市内地铁（可在仁川机场 T1/T2 下车，但不能在这两站上车）以及首尔市执照的市内、社区公交（含深夜、循环公交）。不包含新盆唐线、GTX、首尔以外地铁、广域/机场巴士及其他地区执照公交。若在首尔市内上车、在京畿道等范围外下车，该卡不能作为出站凭证，需另付车费。

短期券官方标价（韩元，以首尔市交通页面为准）：1日 5,000；2日 8,000；3日 10,000；5日 15,000；7日 20,000。使用从充值当天首班车起算，一般不能提前充后面的日期。实体卡本身可能另计工本费，请在售卡处确认。询问：多山呼叫中心 120，或 T-money 客户中心 1644-0088。

机场往来

据 VisitKorea《机场交通指南》（该页注明最近更新 2026年5月22日）：

  • AREX 机场铁路：仁川机场往首尔站，直达约 43 分钟（1号航站楼）或约 51 分钟（2号航站楼）；普通列车经弘大入口、数码媒体城等站，分别约 59 分钟、66 分钟。直达票可在网上或车站购买；普通列车可用各类交通卡。
  • 机场大巴（Limousine）：线路覆盖首尔及韩国其他地区。仁川线通常需预先购票，现场现金或交通卡可能无法直接上车，请在航站楼售票处或售票机购票。
  • 出租车：普通、豪华、大型和国际出租车在指定上客点候客。国际出租车一般需要预约。可支付现金、信用卡或交通卡。请走官方出租车站，并确认司机打表。

夜间公交、金浦、金海、济州机场的接驳，同样见 VisitKorea 该指南。问询可打 1330。

5. 礼仪

  • 见面或致谢时可微微鞠躬，接收名片、钱或物品时尽量用双手。
  • 韩国日常餐饮一般没有付小费的习惯。若账单已写明服务费，按账单支付即可，不必额外再加，除非菜单或店规另有说明。
  • 进入需要脱鞋的餐厅或传统住宿，把鞋放在指定位置。
  • 不要把筷子直立插在饭碗里；用餐时尽量不要过于大声。地铁和公交上也请控制音量。
  • 排队、靠右或按车站标识站立。过马路要看信号，中国驻济州总领馆曾提醒不要乱穿马路。
  • 未经允许不要随意拍摄他人，以免引发纠纷。公共场所禁烟范围较广，请看标识，违者可能被罚款。

6. 天气与行装

韩国四季分明，首尔等内陆城市冬季常可低于冰点、干燥多风；夏季闷热，并有梅雨和暴雨；春季可能遇到扬尘或较大温差；秋季通常凉爽，适合出行，山区降温更早。济州、釜山海风更明显，体感会与市区不同。

  • 春季：薄外套和可叠加的内搭，必要时准备口罩。
  • 夏季：透气衣物、雨具、防晒和舒适步行鞋；山区仍可能需要一件薄外套。
  • 秋季：长袖和一件暖和的外套，早晚温差大。
  • 冬季：厚大衣、围巾手套、防滑鞋底；室内供暖足，方便穿脱更舒服。

无论季节，都建议穿适合走路的鞋，并预留一件可防风的外衣。具体预报请出发前查看气象厅或可靠天气应用，不要只按往年印象打包。

7. 上网：SIM / eSIM / 随身 Wi-Fi

短期游客常见做法包括：在机场或市区办理韩国预付 SIM、购买 eSIM，或租用随身 Wi-Fi。仁川、金浦、金海、济州等机场通常有电信商或旅游通信柜台，具体套餐和价格经常变动，本页不列举金额，请在柜台或官方渠道比较覆盖范围、流量和是否含通话。

主要移动运营商包括 SKT、KT、LG U+ 及其旅游品牌或合作柜台。eSIM 需要手机支持并已解锁。部分旅游预付卡（如与交通卡结合的产品）也可能提供上网功能，办理前看清有效期和限速条款。

也可使用中国境内运营商的国际漫游，费用通常较高，出发前向自己的运营商确认开通方式和收费。咖啡馆和部分商场有公共 Wi-Fi，但不要在公共网络里登录网银或输入重要验证码。

沟通卡、常用句和 1330 在信号不好时仍然有用。可把本站「攻略」页先加到主屏幕，方便离线查看已缓存的内容。

8. 常见陷阱，请小心

  • 退税黄牛：不要把护照和退税单交给主动搭讪的「代办」。应按商店或官方退税点流程办理，出境仍可能要接受海关查验。
  • 出租车：在机场和车站走官方出租车上客点，确认打表。对主动揽客、拒绝打表或临时加价的车辆应拒绝。可使用当地叫车应用或酒店代叫。
  • 兑换与付款：只在有公示汇率的正规兑换所换钱，当面点清。扫码支付时核对店名和金额，不要扫来路不明的二维码。
  • 购物：对「特别便宜的正品化妆品」、无证摊贩和没有正规小票的商品保持警惕。详情见「买妆」和「购物」页。
  • 拉客：对街上强力推销的酒吧、按摩、「免费」参观要谨慎，先问清价格，不要把护照抵押给陌生人。
  • 行程与证件：护照和现金分开存放；重要证件拍照备份。中国驻外机构也曾提醒注意住宿门锁、出租车发票和户外活动安全。

如果已经发生财物损失或人身危险，先拨 112 或 119，再视需要联系大使馆领事保护电话或 12308。
